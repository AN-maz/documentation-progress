# 🚀 Projects — Dart Fundamentals

Folder ini berisi **project capstone**: latihan yang memakai materi dari beberapa pertemuan sekaligus.

> Kenapa dipisah dari `lab/pertemuan-XX/`?
> Karena project biasanya lintas topik (mis. butuh variabel + loop + fungsi).
> Yang murni satu topik tetap ambush di folder lab pertemuan masing-masing.

## Aturan

1. Satu folder per project: `NN-nama-project/`.
2. Setiap folder project punya `README.md` berisi: tujuan, fitur, dan lingkup materi yang dipakai.
3. Berisi `main.dart` sebagai entry point.
4. Semua kode Dart berada di dalam folder project — tidak menunjuk ke `lib/`/`bin/` level atas.
