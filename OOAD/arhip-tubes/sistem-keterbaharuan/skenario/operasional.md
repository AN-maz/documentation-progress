# **Tabel 1. Use Case UC_OPS_NEW01 – Auto-Request Pembelian Barang**

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**            | Auto-Request Pembelian Barang                                                                                                                                                                                                                                                                                                                                   |
| **ID**                       | UC_OPS_NEW01                                                                                                                                                                                                                                                                                                                                                    |
| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                                                            |
| **Primary Actor**            | Logistik                                                                                                                                                                                                                                                                                                                                                        |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                                       |
| **Stakeholder and Interest** | **Logistik:** Ingin memastikan stok perangkat operasional (seperti kabel, router, dan ONT) selalu berada dalam batas aman tanpa harus melakukan pengecekan manual.<br><br>**Finance:** Ingin memperoleh rekap kebutuhan anggaran pembelian barang yang tercatat secara otomatis oleh sistem.                                                                    |
| **Brief Description**        | Menjelaskan proses sistem membuat draf Purchase Request (PR) secara otomatis ketika mendeteksi jumlah stok suatu barang di gudang telah mencapai batas minimum (threshold).                                                                                                                                                                                     |
| **Trigger**                  | Sistem mendeteksi jumlah stok barang berada di bawah batas minimum yang telah dikonfigurasi.                                                                                                                                                                                                                                                                    |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                                        |
| **Relationship**             | **Association:** Logistik<br>**Include:** –<br>**Extend:** –                                                                                                                                                                                                                                                                                                    |
| **Normal Flow of Events**    | 1. Sistem memonitor stok gudang secara real-time.<br>2. Sistem mendeteksi barang mencapai batas minimum.<br>3. Sistem membuat draf Purchase Request (PR) secara otomatis.<br>4. Sistem mengirimkan notifikasi PR ke dashboard Logistik.<br>5. Logistik memvalidasi dan menekan tombol **"Kirim ke Finance"**.<br>6. Sistem meneruskan PR ke departemen Finance. |
| **Exceptional Flows**        | **5E.** Logistik mengetahui bahwa barang telah dipesan sebelumnya secara manual sehingga membatalkan draf PR otomatis untuk menghindari pesanan ganda.                                                                                                                                                                                                          |

| **ID**                       | UC_OPS_NEW02                                                                                                                                                                                                                                                                                                                                                                    |
| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                                                                            |
| **Primary Actor**            | Teknisi                                                                                                                                                                                                                                                                                                                                                                         |
| **Secondary Actor**          | Logistik                                                                                                                                                                                                                                                                                                                                                                        |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                                                       |
| **Stakeholder and Interest** | **Teknisi:** Membutuhkan proses pengambilan barang dari gudang yang cepat dan praktis sebelum menuju lokasi instalasi.<br><br>**Logistik:** Menginginkan pencatatan barang keluar (inventory out) yang akurat dan diperbarui secara real-time.                                                                                                                                  |
| **Brief Description**        | Menjelaskan proses Teknisi memindai QR Code atau Barcode perangkat saat pengambilan di gudang sehingga jumlah stok pada sistem pusat berkurang secara otomatis.                                                                                                                                                                                                                 |
| **Trigger**                  | Teknisi mengambil perangkat dari gudang untuk keperluan instalasi atau maintenance.                                                                                                                                                                                                                                                                                             |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                                                        |
| **Relationship**             | **Association:** Teknisi, Logistik<br>**Include:** –<br>**Extend:** –                                                                                                                                                                                                                                                                                                           |

Sistem mencocokkan serial number dengan database gudang pusat.<br>4. Sistem menampilkan detail barang dan mencatat ID Teknisi sebagai pembawa perangkat.<br>5. Sistem secara otomatis mengurangi jumlah stok yang tersedia. |

# **Tabel 4. Use Case UC_OPS_NEW04 – Audit Keuangan Otomatis**

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Use Case Name**            | Audit Keuangan Otomatis                                                                                                                                                                                                                                                                                                                                                                    |
| **ID**                       | UC_OPS_NEW04                                                                                                                                                                                                                                                                                                                                                                               |
| **Importance Level**         | Medium                                                                                                                                                                                                                                                                                                                                                                                     |
| **Primary Actor**            | Finance                                                                                                                                                                                                                                                                                                                                                                                    |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                                                                  |
| **Stakeholder and Interest** | **Finance:** Ingin menghemat waktu rekonsiliasi data dan meminimalkan kesalahan perhitungan antara mutasi pembayaran masuk dengan data tagihan pada sistem.                                                                                                                                                                                                                                |
| **Brief Description**        | Menjelaskan proses rekonsiliasi otomatis terhadap data pembayaran dari payment gateway dengan daftar tagihan pelanggan.                                                                                                                                                                                                                                                                    |
| **Trigger**                  | Finance menjalankan proses audit secara manual melalui tombol sinkronisasi atau sistem menjalankan **cron job** pada akhir jam kerja.                                                                                                                                                                                                                                                      |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                                                                   |
| **Relationship**             | **Association:** Finance<br>**Include:** –<br>**Extend:** –                                                                                                                                                                                                                                                                                                                                |
| **Normal Flow of Events**    | 1. Finance memilih menu **Audit Otomatis** pada modul keuangan.<br>2. Sistem mengambil riwayat transaksi masuk dari payment gateway pihak ketiga.<br>3. Sistem mencocokkan nominal pembayaran dan ID transaksi dengan daftar tagihan pelanggan.<br>4. Sistem mengubah status tagihan menjadi **"Lunas"** apabila data sesuai.<br>5. Sistem menampilkan laporan hasil audit kepada Finance. |
| **Exceptional Flows**        | **3E.** Terdapat transaksi dengan nominal berbeda atau ID transaksi tidak dikenali. Sistem memasukkan transaksi tersebut ke dalam tab **"Unmatched"** dan meminta Finance melakukan verifikasi serta alokasi secara manual.                                                                                                                                                                |
