| **Brief Description**        | Di dalam *use case* ini dijelaskan alur sistem mengirimkan notifikasi WhatsApp kepada pelanggan setelah proses aktivasi layanan berhasil dilakukan.                                                                                                                                                                                                    |
| **Trigger**                  | Status layanan pelanggan berhasil diubah menjadi aktif oleh divisi NOC.                                                                                                                                                                                                                                                                                |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                               |
| **Relationship**             | **Association:** -<br>**Include:** -<br>**Extend:** Perluasan (*Extend*) dari **Mengaktifkan Akses Internet (UC_OP08)**.                                                                                                                                                                                                                               |
| **Normal Flow of Events**    | 1. Sistem mendeteksi bahwa layanan pelanggan telah berhasil diaktifkan.<br>2. Sistem mengambil data pelanggan yang diperlukan untuk pengiriman notifikasi.<br>3. Sistem menyusun pesan informasi aktivasi layanan.<br>4. Sistem mengirimkan notifikasi WhatsApp kepada pelanggan.<br>5. Sistem mencatat status pengiriman notifikasi sebagai berhasil. |
| **Alternate Flows**          | -                                                                                                                                                                                                                                                                                                                                                      |
| **Exceptional Flows**        | 4E. Pengiriman notifikasi tidak berhasil dilakukan karena nomor pelanggan tidak valid atau layanan pengiriman pesan sedang mengalami gangguan. Sistem mencatat kegagalan pengiriman tanpa memengaruhi status aktivasi layanan pelanggan.                                                                                                               |
