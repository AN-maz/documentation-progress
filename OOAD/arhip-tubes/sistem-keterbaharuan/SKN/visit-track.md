

# **1. Scenario: Mengecek Cakupan Jaringan (ODP)**

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Use Case Name**            | Mengecek Cakupan Jaringan (ODP)                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **ID**                       | UC_VT_NEW01                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Primary Actor**            | Sales                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Secondary Actor**          | Sistem Operasional (External System)                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Stakeholder and Interest** | **Sales:** Ingin memastikan bahwa di lokasi calon pelanggan terdapat *port* ODP yang kosong sebelum memberikan kepastian pemasangan.<br><br>**NOC:** Ingin mengurangi pembatalan pemasangan akibat kondisi jaringan penuh (*full port*).                                                                                                                                                                                                                                  |
| **Brief Description**        | Menjelaskan proses Sales melakukan pengecekan ketersediaan jaringan secara *real-time* melalui integrasi API dengan Sistem Operasional.                                                                                                                                                                                                                                                                                                                                                    |
| **Trigger**                  | Sales berada di lokasi calon pelanggan dan menekan tombol **"Cek Coverage"**.                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Relationship**             | **Association:** Sales, Sistem Operasional<br>**Include:** -<br>**Extend:** -                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Normal Flow of Events**    | 1. Sales membuka menu **Cek Coverage** pada aplikasi VisitTrack.<br>2. Sales memilih **"Gunakan Lokasi Saat Ini"** atau memasukkan koordinat secara manual.<br>3. Sistem mengirimkan permintaan (*request*) API ke Sistem Operasional.<br>4. Sistem Operasional memverifikasi ODP terdekat beserta jumlah *port* yang tersedia.<br>5. Sistem menampilkan status **"Jaringan Tersedia"** beserta estimasi jarak penarikan kabel.<br>6. Sales melanjutkan proses penawaran kepada pelanggan. |
| **Alternate Flows**          | **5A.** Apabila status area **"Penuh"** atau **"Belum Terjangkau"**, sistem menampilkan rekomendasi untuk memasukkan prospek ke dalam daftar tunggu (*Demand Area*).                                                                                                                                                                                                                                                                                                                       |
| **Exceptional Flows**        | **3E.** Terjadi *timeout* atau gangguan koneksi API ke Sistem Operasional. Sistem menampilkan pesan peringatan dan meminta Sales mencoba kembali beberapa saat kemudian.                                                                                                                                                                                                                                                                                                                   |
