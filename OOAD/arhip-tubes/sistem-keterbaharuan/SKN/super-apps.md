# Scenario 1: Membeli Paket Tambahan (Speed Booster)

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                        |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**            | Membeli Paket Tambahan (Speed Booster)                                                                                                                                                                                                                                                                                |
| **ID**                       | UC_NEW_01                                                                                                                                                                                                                                                                                                             |
| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                  |
| **Primary Actor**            | Pelanggan                                                                                                                                                                                                                                                                                                             |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                             |
| **Stakeholder and Interest** | **Pelanggan:** Ingin menaikkan kecepatan internet secara instan untuk kebutuhan mendesak.                                                                                                                                                                                                                             |
| **Brief Description**        | Alur pelanggan membeli paket kecepatan tambahan (Speed Booster) yang langsung aktif dan terkonfigurasi ke sistem jaringan menggunakan saldo C-Pay.                                                                                                                                                                    |
| **Trigger**                  | Pelanggan memilih menu **"Speed Booster"** pada aplikasi.                                                                                                                                                                                                                                                             |
| **Normal Flow of Events**    | 1. Pelanggan memilih paket kecepatan yang diinginkan.<br>2. Sistem menampilkan ringkasan tagihan.<br>3. Pelanggan mengonfirmasi pembelian.<br>4. Sistem mengecek dan memotong saldo C-Pay.<br>5. Sistem mengirimkan perintah API ke NOC untuk menaikkan bandwidth.<br>6. Sistem menampilkan bukti pembelian berhasil. |
| **Exceptional Flows**        | **4E.** Saldo C-Pay tidak mencukupi. Sistem membatalkan transaksi dan menyarankan pelanggan melakukan Top Up.                                                                                                                                                                                                         |

# Scenario 3: Melaporkan Gangguan Layanan

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**            | Melaporkan Gangguan Layanan                                                                                                                                                                                                                                                                                                                    |
| **ID**                       | UC_NEW_03                                                                                                                                                                                                                                                                                                                                      |
| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                                           |
| **Primary Actor**            | Pelanggan                                                                                                                                                                                                                                                                                                                                      |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                      |
| **Stakeholder and Interest** | **Pelanggan:** Ingin melaporkan gangguan teknis secara mandiri tanpa harus menghubungi Call Center.                                                                                                                                                                                                                                            |
| **Brief Description**        | Alur pembuatan Trouble Ticket oleh pelanggan yang terintegrasi langsung dengan antrean Customer Service pada Sistem Operasional.                                                                                                                                                                                                               |
| **Trigger**                  | Pelanggan mengalami gangguan internet dan membuka menu **"Lapor Gangguan"**.                                                                                                                                                                                                                                                                   |
| **Normal Flow of Events**    | 1. Pelanggan mengisi formulir gangguan teknis.<br>2. Pelanggan melampirkan foto indikator modem (opsional).<br>3. Pelanggan menekan tombol **"Kirim Laporan"**.<br>4. Sistem memvalidasi kelengkapan data.<br>5. Sistem membuat Trouble Ticket dan meneruskannya ke Sistem Operasional.<br>6. Sistem menampilkan nomor tiket kepada pelanggan. |
| **Exceptional Flows**        | **4E.** Data wajib belum lengkap. Sistem menolak pengiriman dan meminta pelanggan melengkapi formulir.                                                                                                                                                                                                                                         |

# Scenario 4: Mengelola Promo & Diskon Hotel

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**            | Mengelola Promo & Diskon Hotel                                                                                                                                                                                                                                                                                                      |
| **ID**                       | UC_NEW_04                                                                                                                                                                                                                                                                                                                           |
| **Importance Level**         | Medium                                                                                                                                                                                                                                                                                                                              |
| **Primary Actor**            | Divisi Walanja                                                                                                                                                                                                                                                                                                                      |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                           |
| **Stakeholder and Interest** | **Divisi Walanja:** Ingin meningkatkan penjualan kamar hotel melalui pemberian kode promo dan voucher diskon.                                                                                                                                                                                                                       |
| **Brief Description**        | Alur Divisi Walanja membuat dan mempublikasikan promo hotel yang akan ditampilkan pada aplikasi pelanggan.                                                                                                                                                                                                                          |
| **Trigger**                  | Divisi Walanja memulai campaign pemasaran baru.                                                                                                                                                                                                                                                                                     |
| **Normal Flow of Events**    | 1. Divisi Walanja membuka modul **"Promo Hotel"**.<br>2. Divisi Walanja memasukkan kode promo, nilai diskon, dan masa berlaku.<br>3. Divisi Walanja menekan tombol **"Publikasikan"**.<br>4. Sistem memvalidasi tanggal dan nilai diskon.<br>5. Sistem menyimpan serta mengaktifkan promo sehingga tampil pada dashboard pelanggan. |
| **Exceptional Flows**        | **4E.** Masa berlaku yang dimasukkan berada pada tanggal yang telah lewat. Sistem menampilkan pesan kesalahan dan membatalkan publikasi promo.                                                                                                                                                                                      |
