# **2. Scenario: Mengajukan Klaim Lembur**

| **Atribut**                  | **Keterangan**                                                                                                                                                                                                                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**            | Mengajukan Klaim Lembur                                                                                                                                                                                                                                                                                   |
| **ID**                       | UC_ABS_NEW02                                                                                                                                                                                                                                                                                              |
| **Importance Level**         | Medium                                                                                                                                                                                                                                                                                                    |
| **Primary Actor**            | Karyawan                                                                                                                                                                                                                                                                                                  |
| **Secondary Actor**          | HR                                                                                                                                                                                                                                                                                                        |
| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                 |
| **Stakeholder and Interest** | **Karyawan:** Ingin memperoleh pengakuan dan kompensasi atas pekerjaan yang dilakukan di luar jam kerja.<br><br>**HR:** Ingin memastikan bahwa jam lembur sesuai dengan data presensi dan pekerjaan yang dilakukan.                                                                                       |
| **Brief Description**        | Menjelaskan proses karyawan mengajukan klaim lembur dengan memasukkan waktu lembur dan deskripsi pekerjaan yang telah diselesaikan.                                                                                                                                                                       |
| **Trigger**                  | Karyawan telah menyelesaikan pekerjaan di luar jam kerja normal.                                                                                                                                                                                                                                          |
| **Type**                     | External                                                                                                                                                                                                                                                                                                  |
| **Relationship**             | **Association:** Karyawan, HR<br>**Include:** -<br>**Extend:** -                                                                                                                                                                                                                                          |
| **Normal Flow of Events**    | 1. Karyawan membuka menu **Klaim Lembur**.<br>2. Karyawan mengisi jam mulai, jam selesai, dan deskripsi pekerjaan.<br>3. Karyawan menekan tombol **Ajukan Klaim**.<br>4. Sistem mencocokkan data lembur dengan log presensi pulang.<br>5. Sistem menyimpan pengajuan dengan status **Menunggu Validasi**. |
| **Alternate Flows**          | -                                                                                                                                                                                                                                                                                                         |
| **Exceptional Flows**        | **4E.** Sistem tidak menemukan data presensi pulang sehingga pengajuan ditolak. Sistem meminta karyawan melakukan koreksi presensi terlebih dahulu sebelum mengajukan kembali.                                                                                                                            |

| **Importance Level**         | High                                                                                                                                                                                                                                                                                                                                                                                |

| **Use Case Type**            | Main Case                                                                                                                                                                                                                                                                                                                                                                           |
| **Stakeholder and Interest** | **HR:** Memiliki kewenangan untuk memverifikasi dan memutuskan pengajuan izin, cuti, sakit, maupun lembur.<br><br>**Karyawan:** Mengharapkan proses persetujuan yang cepat dan transparan.                                                                                                                                                                                          |
| **Brief Description**        | Menjelaskan proses HR meninjau, menyetujui, atau menolak pengajuan ketidakhadiran dan klaim lembur yang diajukan oleh karyawan.                                                                                                                                                                                                                                                     |
| **Trigger**                  | HR membuka menu **Validasi Pengajuan** pada aplikasi.                                                                                                                                                                                                                                                                                                                               |
| **Type**                     | External                                                                                                                                                                                                                                                                                                                                                                            |
| **Relationship**             | **Association:** HR, Karyawan<br>**Include:** -<br>**Extend:** -                                                                                                                                                                                                                                                                                                                    |

Sistem memperbarui status pengajuan dan mengirimkan notifikasi kepada karyawan. |
| **Alternate Flows**          | -                                                                                                                                                                                                                                                                                                                                                                                   |
